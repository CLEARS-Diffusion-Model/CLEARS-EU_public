# CLEARS-EU_public
The CLEARS-EU model estimates national-level adoption pathways for 25 EU countries for rooftop PV and residential battery storage using a two-stage approach that integrates economic evaluation with diffusion dynamics (Hartvig, 2025; Hartvig & Szabó, 2025). First, the model calculates the net present value (NPV) of investing in battery storage systems connected to rooftop PVs for heterogeneous households, accounting for region-specific load profiles, consumption levels, and radiation characteristics. Second, potential adopters identified by the NPV analysis are used in Bass diffusion models to simulate the cumulative adoption trajectory, capturing non-financial drivers and producing an S-shaped growth curve.
